# @wirework/engine-react-grid-layout

The react-grid-layout layout engine for Wirework: cells on a 12-column grid
with drag and resize in edit mode. Peers: `react`, `react-dom`.

```ts
import { reactGridLayoutEngine } from "@wirework/engine-react-grid-layout";
import "@wirework/engine-react-grid-layout/styles.css";
layoutEngines.register(reactGridLayoutEngine); // page templates use engine: "react-grid-layout"
```
