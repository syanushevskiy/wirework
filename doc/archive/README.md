# Archive

Historical material kept for reference. Nothing here is built, imported or
current — the packages under `packages/` and the design docs in `doc/` are.

- `whiteboard-models/` — the first TypeScript transcription of the design
  sketch (`widgets.jpg`), written before the monorepo existed. Its
  `PageViewModel`, `LayoutEngine` and numeric-keyed rows were superseded by
  `@wirework/schema`; kept because the sketch's intent (filters, refresher,
  template pills, page cache) is still ahead of the implementation.
- `2026-09-02-team-tiger-sketch-review.txt` — Team Tiger's first review of
  that sketch and transcription.
